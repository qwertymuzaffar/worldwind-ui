# Code of conduct

This project welcomes contributions and questions from everyone. To keep it that way:

- Be respectful. Disagree with ideas, not with people. No harassment, insults, or discrimination of
  any kind, in issues, pull requests, discussions, or anywhere else the project is represented.
- Assume good intent and ask before judging. Most misunderstandings are about words, not people.
- Keep feedback specific and about the work. "This breaks when the layer is disabled" helps;
  "this is sloppy" does not.
- Respect the maintainers' time. Search before filing, fill in the templates, and accept that not
  every request will be taken.

If something happens that you think breaks these rules, contact the maintainer privately through
GitHub (a direct message, or a report on the offending content). Reports are handled in confidence,
and behaviour that continues after a warning leads to being blocked from the project.
