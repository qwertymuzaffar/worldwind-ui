# Demos

Both demos are the published packages running in your browser: a 3D globe with imagery, a GeoJSON layer styled per feature, placemarks, a route, and every widget.

- [React demo](/react/){target="_self"}: `examples/react-demo`, built with Vite.
- [Angular demo](/angular/){target="_self"}: `examples/angular-demo`, a zoneless Angular CLI app.
