worldwind-ui UI libraries for NASA WorldWind

One framework-agnostic core, thin adapters for React and Angular, ready-made widgets, and a fake WorldWind for tests. Both demos below are the real packages running in your browser.

React demo

Built with react-worldwind: components, hooks and widgets.

Angular demo

Built with ngx-worldwind: standalone components with signal inputs, zoneless.

worldwind-kit on npm

The core: globe controller, layers, camera, picking, shapes, testing fake, Vite plugin.
